这个站是自己搭的。

不是"用了某个平台的博客",是从一个空目录开始,一行一行配出来的。配色、字号、卡片间距、文章列表显示几篇、要不要显示阅读时长 —— 这些事以前在别人的后台里只能选现成的选项,现在是自己写进去的。

听起来像是给自己找事。但真动手之后发现,麻烦的部分其实不在这里:配置文件写一次就完了,之后几个月都不会再碰。真正每天都在用的,是"改一个字,浏览器立刻变"的那个循环。

<!--more-->

## 为什么写

写字这件事有个很奇怪的特点:想的时候觉得都想清楚了,落笔的时候才发现一半是空的。

那些"我懂了"的东西,写下来会给卡住的地方;而卡住的地方,通常不是知识不够,是自己没真懂。所以写博客对技术人来说不是分享,是校验。

至于要不要给人看 —— 有人看是好事,但那是副产品。首页上现在只有三篇文章,其中一篇还是语法说明,没什么可看的。这很正常,写作的收益本来就不在当下。

## 会写什么

技术为主。踩过的坑、读源码时的困惑、某个设计为什么长成那样、以及一些"当时觉得对后来发现错了"的判断。

也会有别的。一些不值得单独成篇的念头,一些与代码无关的观察。分不分类其实无所谓,写了就是了。

## 怎么改

想换站名和副标题,改 `hugo.yaml` 里的 `title` 和 `params.sidebar`。

想换成自己的头像,替换 `assets/img/avatar.png`。

想写新文章:

```bash
hugo new content post/文章名/index.md
```

然后 `hugo server -D` 在本地看效果。就这样。
